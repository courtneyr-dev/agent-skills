# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith until they prove otherwise. Criticize
work, not people.

## Expected

- Give feedback on the thing, with specifics: what breaks, when, and what you expected instead.
- Accept that maintainers say no. A skill that does not fit this collection is not an insult.
- Correct yourself when you turn out to be wrong. Everyone here has been.

## Not acceptable

- Harassment, insults, or demeaning comments, whether about a person's identity or their code.
- Publishing someone's private information.
- Sustained disruption: reopening settled arguments, brigading a decision, or bad-faith rules
  lawyering.

## Attribution disputes

This project takes authorship seriously and will get it wrong sometimes. If you believe a skill
here is yours, or is attributed to the wrong person, open an issue with the original source and
ideally a first-commit date. It will be corrected or removed. Attribution errors get fixed, not
argued about — that applies to the maintainer too.

## Enforcement

Report conduct issues by opening an issue, or privately via GitHub if it involves someone in the
thread. The maintainer will respond as quickly as a personal project allows. Consequences range
from a request to change behavior, to having comments removed, to being blocked from the
repository.

Adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/),
shortened because a code of conduct nobody reads protects nobody.
