# Sources, editions and rights

Verification status: cited from the author's knowledge on 2026-11-25. The build ran without network access, so DOIs and editions weren't resolved live; run them through `edu-research-review`'s citation check (or resolve each DOI) before quoting. The skill paraphrases methods; it copies no text, tables or figures.

Research on one population (for example novice adult learners) doesn't establish an effect in another (K-12 BCIT classrooms, workplace onboarding). The procedures use these sources as design rationale to test, not as proof that a package works.
