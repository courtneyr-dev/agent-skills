# BCIT teacher-education module (fixture)

The addendum's BCIT professor demonstration: a methods-course module combining an authentic business task, computing practice, pedagogical rationale and calibrated assessment criteria. Built with `edu-trainer-development` (teacher-education mode); answer keys are checked by execution with `edu-answer-key-check`. Fixture Co, its student-run store and every person are fictional.

| File | What it is |
|---|---|
| `manifest.json` | Module manifest checked by `edu-trainer-development/scripts/package.py check` |
| `module.md` | The module: context, authentic task, computing practice, rationale, microteaching cycle, observation, criteria, calibration, evidence lines, standards labels, supervisor decisions |
| `answer-key.json` | Verified key: 4 spreadsheet items, 1 calculation, 2 SQL queries |
| `answer-key-draft.json` | Draft key with one intentionally incorrect key (Q2 = 180) |
| `candidate-solutions.json` | Sample candidate solution with two intentionally incorrect answers (Q2 formula, Q6 query missing GROUP BY) |
| `rubric.json` | Four criteria, one evidence line each, six generated practice anchors |
| `observation-instrument.json` | Five-item microteaching instrument; no observations recorded |
| `calibration-exercise.md`, `calibration-practice-ratings.json` | Supervisor rehearsal; the agreement script returns practice-only |
| `evidence-plan.json` | Plan to collect actual candidate evidence; result fields empty |
| `manifest-merged-evidence.json` | Counterexample: technology fluency inferred from subject mastery, credential readiness claimed from microteaching, and an ISTE Students label ("Empowered Learner") tagged as an Educator role |

Standards: NBEA content areas and ISTE Educator roles appear as labels only. No standard IDs or text are claimed; alignment stays unverified.
