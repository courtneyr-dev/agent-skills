# Hymn lyrics lookup

### Step 4: Look Up Hymn Lyrics

For each hymn in the bulletin:

1. **Identify the hymn** by number and/or title
2. **Look up the full lyrics** — all stanzas
3. **Include attribution**: author, composer, tune name, year, copyright status
4. **Note the hymnal source** if listed (e.g., "UMH 110" = United Methodist Hymnal #110)

Format each hymn as:

```markdown
#### [Hymn Title]

**Hymnal:** [Source and number]
**Author:** [Lyricist name, year]
**Tune:** [Tune name]
**Composer:** [Composer name, year]
**Copyright:** [Public domain / Copyright holder]

> Verse 1
> [Full lyrics of verse 1]
>
> Verse 2
> [Full lyrics of verse 2]
>
> [Continue for all verses]
```
