# Bulletin extraction

### Step 1: Extract Bulletin Content

Read the bulletin image or text. Extract ALL of the following (skip any that aren't present):

- Church name, denomination, address, phone, website, email
- Service date and time
- Service type (e.g., "Fourth Sunday after Epiphany")
- Pastor/clergy names and roles
- Order of worship (every element in sequence)
- All scripture references (readings, responsive readings, sermon text)
- Hymn numbers, titles, and any noted tune names
- Sermon title and preacher (if listed)
- Announcements and upcoming events
- Prayer requests or prayer list
- Mission statement or church vision
- Staff/leadership list
- Any other content (dedications, memorials, volunteer schedules, etc.)
