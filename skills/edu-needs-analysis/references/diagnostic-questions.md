# Diagnostic questions

Each key in a case's `evidence` answers one question. A value counts only with a source: an observed attempt, a system log, a work sample, a document or an interview with the people who do the work. A manager's belief about the cause is a hypothesis, not evidence.

## Knowledge and skill (individual)

| Key | Question | Good evidence |
|---|---|---|
| `can_do_when_required` | Could the performer do the task correctly now if it were required and everything else were in place? | An observed attempt with the real tool and data ready |
| `did_it_before` | Has the performer ever done the task correctly? | Work history, logs, past work samples |
| `performed_often` | Is the task done often enough to stay fluent? | Task frequency from logs or schedules |

Routing: a performer who can do the task has no skill gap, so instruction won't help. A performer who never could needs instruction. A skill that faded needs practice; a frequent task done wrong needs feedback.

## Environment

| Key | Factor | Question |
|---|---|---|
| `expectations_clear` | Information | Do performers know what good performance looks like and when it is expected? |
| `feedback_given` | Information | Do performers get timely, specific feedback on how they performed? |
| `tools_adequate` | Resources | Do the tools, systems and materials let a skilled person do the task? |
| `process_clear` | Resources | Does the process let the task be done as intended, without conflicting steps or approvals? |
| `access_ok` | Resources | Do performers have the access, permissions, time and accommodations the task needs? |
| `consequences_aligned` | Incentives | Is doing the task well rewarded, and is skipping it free of hidden rewards? |

Each false value routes to a remedy and its owner: the tool owner, the process owner, the access owner or the manager who sets consequences. These problems don't need a course.

## Audience and task analysis

- Audience: who performs, how many, their context and prior knowledge, and their access needs. Record actual accommodation plans when they exist; never infer a diagnosis or a learning style.
- Task: the steps, how often it happens, what failure costs and the conditions (tools, data, approvals).

## What the skill does not ask

It doesn't ask about learning styles, personality or capacity. Capacity questions concern individuals and belong to people with the authority and data to answer them, not to an agent.
